# Tauri parity matrix

Status as of 2026-10-23: implementation is underway through the native bridge and initial Rust raster jobs. `Pending` means the Tauri implementation and its gate have not passed. Electron behavior is a baseline, not a Tauri claim. See [shell validation](TAURI_SHELL_VALIDATION.md) and the deferred [validation checklist](TAURI_VALIDATION_CHECKLIST.md).

| Area | Electron baseline | Tauri proof required | Status |
| --- | --- | --- | --- |
| Host and fallback | Hidden background host, optional tray, main workspace for settings/history/queue | Native startup, single instance, tray/menu, quit, host accessibility fallback on Ubuntu and Windows | Ubuntu shell process launched; single-instance CLI wheel handoff now in code; interactions pending |
| Windows | Main workspace, transparent nonfocusable citrus wheel, compact image/video editor | Window creation, close/reopen, topmost, pointer positioning, focus, drag/drop, multi-monitor and mixed DPI | Tauri code now manages workspace, wheel, image/video editor and dynamic preview windows; lifecycle and platform behavior pending |
| Renderer | React/Vite workspace and wheel, image/video editor hosts, PDF workspace | Same layout/fonts/high contrast and keyboard behavior in WebKitGTK and WebView2 | Pending |
| Bridge | Context-isolated preload with validated IPC and sender checks | Typed Tauri adapter, command permissions, per-window session checks and event cleanup | Typed adapter and native selection/drop bridge compile; per-window authorization and full command coverage pending |
| Settings/data | XDG user data, atomic JSON settings/jobs, diagnostics, clipboard, open/reveal, output dialog | Equivalent local paths and services, Windows native paths, redacted diagnostics | Rust settings and job JSON, dialogs, clipboard, copy/move, terminal, open/reveal and path-free copied diagnostics implemented; integrated tests pending |
| Jobs | Inspection, signature checks, queue, retry/cancel, collision naming and atomic outputs | Route-by-route golden tests, failure/cancel/cleanup and no silent overwrite | Initial queue, retry/cancel, private temporary files and no-overwrite hard-link publication compile; publication is now a non-cancellable state after the final cancellation check. Parity tests pending |
| Images | Bundled Sharp/libvips conversion, bounded previews, orientation, crop/resize/rotate/flip/compress/background/metadata | Rust/libvips probe and tested format matrix, equivalent editor recipes and new output copies | Provisional Rust image crate path supports raster jobs, previews, arbitrary rotation, adjustments, and background canvas. Metadata preservation/editing, codec parity, and libvips distribution remain pending; platform/editor validation is deferred |
| Archives | Local ZIP/TAR/GZIP with bounded entries and traversal/link rejection | Malformed archive, escape, cancellation and round-trip tests | Rust ZIP/TAR/GZIP create/extract and a ZIP round-trip test compile; malformed archive corpus and native job acceptance pending |
| Optional engines | Capability-gated FFmpeg, Poppler, qpdf, Pandoc, LibreOffice, ImageMagick | Probe each executable/feature; hide unavailable routes; process arguments and cancellation tested | FFmpeg/FFprobe and Poppler have local conversion/render tests; FFmpeg snapshot, GIF, waveform video, bounded redaction, ordered split ranges, and ordered media merge are in code. qpdf and Pandoc are capability gated but unavailable on this host; full parity pending |
| Media/previews | Bounded opaque preview URLs, waveforms and PDF raster preview | Safe local protocol, bounded reads, media/PDF/image parity | Window-scoped token protocol and bounded range reads compile; PDF first-page render and quick preview host exist; waveform and platform playback pending |
| Wheel | Shift convert, Alt or Ctrl+Shift tools, Ctrl actions; settings configurable | Real Explorer and GNOME Files drags, pointer/focus/escape, wheel lifetime and accessibility | Tauri native drop event reaches workspace/wheel adapter; GNOME command and optional Windows watcher now signal mode/position in code. External drag remains pending |
| Windows helper | User-mode watcher prototype emits JSON events; drop remains in overlay | MSVC x64 build, isolation, Explorer OLE drag handoff on Windows 10/11 | Tauri reads the fixed local helper protocol and maps configurable modifiers; packaging and real Explorer tests pending |
| Linux integration | Optional GNOME 46/50 extension and XWayland assumptions | GNOME Files drag and extension absent/present on supported Ubuntu LTS; WebKitGTK placement | Extension command template now targets Tauri single-instance CLI; actual GNOME drag/placement pending |
| Packaging | Electron NSIS, deb and AppImage artifacts measured in ADR 0001 | Native Tauri NSIS/deb/AppImage build, install/uninstall/launch, dependency/license/SBOM and installed-size checks | Final package identity and platform build configs are in code; native Windows/Ubuntu install, installed-size and license checks pending |

Do not mark a row complete from source inspection, CI compilation, Wine execution, or browser-only tests alone where the required proof says native interaction. Electron cleanup is authorized on this branch in Phase 7 after code replacements are implemented; Phase 8 validates them.
