# Tauri parity matrix

Status as of 2026-10-24: Tauri is the sole runtime source on `tauri-rt` after the Phase 7 code cutover. `Pending` means a Tauri feature or its native gate has not passed. The Electron column is a historical baseline from Git history, not a current runtime claim. See [shell validation](TAURI_SHELL_VALIDATION.md) and the deferred [validation checklist](TAURI_VALIDATION_CHECKLIST.md).

| Area | Electron baseline | Tauri proof required | Status |
| --- | --- | --- | --- |
| Host and fallback | Hidden background host, optional tray, main workspace for settings/history/queue | Native startup, single instance, tray/menu, quit, host accessibility fallback on Ubuntu and Windows | Ubuntu shell process launched; single-instance CLI wheel handoff now in code; interactions pending |
| Windows | Main workspace, transparent nonfocusable citrus wheel, compact image/video editor | Window creation, close/reopen, topmost, pointer positioning, focus, drag/drop, multi-monitor and mixed DPI | Tauri code now manages workspace, wheel, image/video editor and dynamic preview windows; lifecycle and platform behavior pending |
| Renderer | React/Vite workspace and wheel, image/video editor hosts, PDF workspace | Same layout/fonts/high contrast and keyboard behavior in WebKitGTK and WebView2 | Pending |
| Bridge | Context-isolated preload with validated IPC and sender checks | Typed Tauri adapter, command permissions, per-window session checks and event cleanup | Typed adapter and native selection/drop bridge compile; commands check caller window roles and editor/preview context. Native session and abuse tests pending |
| Settings/data | XDG user data, atomic JSON settings/jobs, diagnostics, clipboard, open/reveal, output dialog | Equivalent local paths and services, Windows native paths, redacted diagnostics | Rust settings and job JSON, dialogs, clipboard, copy/move, terminal, open/reveal and path-free copied diagnostics implemented; integrated tests pending |
| Jobs | Inspection, signature checks, queue, retry/cancel, collision naming and atomic outputs | Route-by-route golden tests, failure/cancel/cleanup and no silent overwrite | Initial queue, retry/cancel, private temporary files and no-overwrite hard-link publication compile; publication is now a non-cancellable state after the final cancellation check. | Optional engines | Capability-gated FFmpeg, Poppler, qpdf, Pandoc, LibreOffice, ImageMagick | Probe each executable/feature; hide unavailable routes; process arguments and cancellation tested | FFmpeg/FFprobe and Poppler have local conversion/render tests; FFmpeg snapshot, GIF, waveform video, bounded redaction, ordered split ranges, and ordered media merge are in code. qpdf and Pandoc are capability gated but unavailable on this host; full parity pending |

Platform playback and full video format parity remain pending |

GNOME and Windows native drag validation remains pending |

| Linux integration | Optional GNOME 46/50 extension and XWayland assumptions | GNOME Files drag and extension absent/present on supported Ubuntu LTS; WebKitGTK placement | Extension command template now targets Tauri single-instance CLI. The local installed extension was refreshed, but GNOME 50 still reports it INACTIVE until a new session; actual GNOME drag/placement remains pending |
| Packaging | Electron NSIS, deb and AppImage artifacts measured in ADR 0001 | Native Tauri NSIS/deb/AppImage build, install/uninstall/launch, dependency/license/SBOM and installed-size checks | Final package identity and platform build configs are in code; native Windows/Ubuntu install, installed-size and license checks pending |
| Cutover | Electron main/preload, Node processing, electron-builder | Tauri as sole host and clean-checkout build | Electron-only source, scripts, dependencies, tests and CI jobs removed on `tauri-rt`; source and browser checks pass, clean-checkout/native acceptance pending |

Do not mark a row complete from source inspection, CI compilation, Wine execution, or browser-only tests alone where the required proof says native interaction. Phase 8 validates the Tauri cutover before release.
