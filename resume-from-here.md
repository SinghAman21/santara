# Santara migration handoff

Branch: `tauri-rt`. The user asked for code work through Phases 1–7 first and moved native/platform checks to Phase 8. They authorized Electron removal on this branch. Do not use sudo to install system packages; the user handles that. Do not add macOS support or touch the untracked user-owned `design/` directory.

The Tauri 2 React/Rust runtime is now the only desktop host in this branch. `src-tauri/` owns windows, bridge services, local jobs, safe previews, built-in raster/subtitle/archive work, and detected FFmpeg/Poppler/qpdf/Pandoc routes. Optional GNOME and Windows integrations remain isolated. Electron source, dependencies, scripts, and Electron-only tests were removed in Phase 7. The code is not certified feature-equivalent: raster metadata and codec behavior, media preview format coverage, and native global drag handoff require Phase 8 work. See [the parity matrix](docs/TAURI_PARITY_MATRIX.md).

Run `npm ci`, `npm run typecheck`, `npm run test`, `npm run build`, `npm run test:e2e`, and `npm run check:release` after a clean checkout. On Ubuntu, build packages with `npm run dist:linux`; on Windows/MSVC x64, use `npm run dist:windows`. Generate actual artifact hashes/sizes and the dependency inventory with `npm run release:report`. Record installed sizes only after installation. Follow [the Phase 8 checklist](docs/TAURI_VALIDATION_CHECKLIST.md) on Windows 10/11 x64 and Ubuntu LTS x64; Wine does not count as native Windows acceptance.

The local Ubuntu host now has `patchelf`, libvips development files, `xvfb`, qpdf, and Pandoc available. ExifTool is absent, so JPEG metadata editing stays hidden here. Earlier interim `.deb` measurements in [packaging notes](docs/TAURI_PACKAGING.md) are not final artifact measurements. The AppImage `linuxdeploy` failure from that interim build still needs a fresh build/diagnosis in Phase 8.
