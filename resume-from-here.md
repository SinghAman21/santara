# Santra migration handoff

Branch: `d2c`. Tauri 2 is the sole runtime. Do not add macOS support, touch the untracked user-owned `design/` directory, or install sudo packages on the user's behalf. The previous Electron implementation remains in Git history.

The frontend migration is recorded in local `type(scope): description` commits, with no pushes. See [UI structure](docs/UI_STRUCTURE.md) for the Penpot 01–10 mapping, `tools/`, `convert/`, `action/`, and `common/` ownership, and deferred capabilities. White surfaces and `#ff5a00` orange replace theme switching. New audio controls play the original locally and queue output recipes; document-family conversions have recoverable review dialogs. Do not interpret planned Penpot screens as implemented backend capabilities.

The wheel requires two complete Shift, Alt, or Ctrl taps during a drag. A selected conversion slice now queues a local job and closes the wheel without showing the workspace; native Tauri drag positions select the slice even when DOM drag events are absent. Drops outside a slice and failed routes hand files to the workspace for review. The image editor's four pan buttons work at normal zoom when a preview is loaded. The local job system preserves the source and writes beside it by default; a configured output folder can override that destination.

Current code checks passed: `npm run typecheck`, `npm run build`, `npm run test` (13 Rust and 5 Windows protocol tests), `npm run test:e2e` (29 Chromium browser tests), `npm run build:windows-hook:cross` (Wine self-test), and `npm run check:release`. The current Ubuntu `.deb` built and its extracted application stayed running through a 10-second isolated D-Bus/Xvfb smoke test. The Windows x64 Tauri application and NSIS installer cross built successfully with user-level rustup/cargo-xwin and Ubuntu NSIS/LLVM packages. `npm run release:report` records both native-target and cross-target installers. Artifact sizes and hashes are in [packaging](docs/TAURI_PACKAGING.md). Generated release reports are not retained in Git.

The installed `/usr/bin/santra` is an older build. Fully quit it and install the current `.deb` before testing; do not interrupt any active local jobs. The GNOME extension files were updated earlier and report `ACTIVE`, though a logout/login may be needed for Shell to load changed code. The current AppImage predates the latest wheel change.

Phase 8 remains open. Validate real GNOME Files and Windows Explorer drags, package installation/removal, editor and conversion output, accessibility, offline operation, and actual installed sizes on Ubuntu LTS x64 and native Windows 10/11 x64. The Windows cross build and Wine helper self-test do not establish native Windows compatibility. Do not claim feature parity or release readiness until the [validation checklist](docs/TAURI_VALIDATION_CHECKLIST.md) and [parity matrix](docs/TAURI_PARITY_MATRIX.md) pass.
