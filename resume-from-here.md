# Santara migration handoff

Branch: `tauri-rt`. Tauri 2 is the sole desktop host on this branch; the earlier Electron code remains in Git history. The user authorized code work through the migration before final native checks and authorized Electron removal on this branch. Do not add macOS support or touch the untracked user-owned `design/` directory. Do not use sudo to install packages; the user handles system packages.

The workspace, citrus wheel, editors, local Rust jobs, optional backend detection, Windows watcher, GNOME extension, and Windows/Linux package configuration are implemented. The wheel now requires a double tap of the configured Shift, Alt, or Ctrl modifier within 400 ms during a drag. The workspace picker also uses double taps. A single press does not open the wheel. The optional platform helpers match this behavior. A global wheel drop without a selected slice now hands inspected files to the workspace; native and DOM drop callbacks are guarded against empty/duplicate events. Wheel hide after drag release allows 600 ms for the native drop event. Image editor directional pan now responds at low zoom. These changes still need real file-manager validation.

Local checks for this update: TypeScript/Vite build and Rust/native protocol tests pass; Windows helper cross-build and Wine state self-test pass; GNOME syntax/schema checks pass. All 20 browser tests pass, covering double tap, single press, wheel drop, workspace handoff, editors and queue. Rebuilt `.deb` and AppImage packages have measured actual installer sizes and hashes in [packaging](docs/TAURI_PACKAGING.md). `npm run release:report` completed; its generated inventory files were not retained in the repository. The previous installed Santara package is older than these source changes and must be reinstalled to see them.

Phase 8 remains open. Run the native [validation checklist](docs/TAURI_VALIDATION_CHECKLIST.md) on Ubuntu LTS x64 and Windows 10/11 x64 with real GNOME Files/Explorer drags, package install/uninstall, backend fixtures, accessibility, offline operation and measured installed sizes. Wine is a helper self-test only and does not satisfy Windows acceptance. The detailed gaps are in [the parity matrix](docs/TAURI_PARITY_MATRIX.md). Do not claim feature parity or release readiness until those gates pass. Generate final artifact sizes and dependency inventory with `npm run release:report`; do not call package metadata an installed-size measurement.
